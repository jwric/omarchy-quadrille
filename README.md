# omarchy-quadrille

[quadrille](../graticule)'s pixel-perfect look on an Omarchy desktop: its five
palettes as Omarchy themes, Departure Mono drawn without antialiasing in every
toolkit, flat whole-pixel surfaces in the shell, and (in progress) shell plugins
and layer-shell panels drawn by quadrille itself.

```
themes/        generated by tools/gen_themes.py from quadrille's theme.rs
fontconfig/    turns antialiasing and subpixel colour off for Departure Mono
tools/         gen_themes.py, install.sh
plugins/       Omarchy shell plugins: a QML kit, a pixel-grid bar, OSD, notifications,
               menu (see plugins/NOTES.md)
layershell/    spike: an iced/quadrille app as a Wayland layer-shell surface
```

## Use

```sh
tools/gen_themes.py        # only after quadrille's palettes change
tools/install.sh           # link the themes, install the fonts and the fontconfig rule
omarchy theme set "Quadrille Terminal"     # or Paper, Phosphor, Amber, Lcd
omarchy font set "Departure Mono"
```

Back to how it was: `omarchy theme set ristretto`,
`omarchy font set "CaskaydiaMono Nerd Font"`, and delete
`~/.config/fontconfig/conf.d/60-quadrille-pixel.conf`.

## Shell plugins

```sh
plugins/install.sh        # the bar, OSD, notifications, menu and CPU/MEM gauges
plugins/stock.sh          # the stock shell again
```

What controls the shell's look, what a plugin can and cannot override, and how
each piece is built: [plugins/NOTES.md](plugins/NOTES.md).

## Pixel scale

A virtual pixel is 2 logical pixels (`--unit`, quadrille's `Auto(2)`), so it is a
whole number of physical pixels only when `2 × monitor scale` is an integer:
scale 1, 1.5 or 2. A monitor at 1.666667 gets uneven pixels.
